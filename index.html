What does 4/4 mean?

The top number says there are four beats in each bar. The bottom number says each beat is a quarter note. Count it as: 1 · 2 · 3 · 4.

Inside the groove

Each quarter-note beat splits into four sixteenth notes. The red markers are the four main beats; the smaller spaces are where the swing and syncopation live.

How it locks

One shared musical clock

The sax phrase gives the groove its melodic voice. Then the 4/4 time signature lays a four-beat bar underneath it, giving the kick, snare, bass, guitar, and tube parts the same place to begin and return to. A crash at the start of the bar acts like a bright signpost, while every part follows the same 16-step count, keeping the full audio in sync.
